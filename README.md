# Proyecto S.HP

**Almacenamiento avanzado de archivos, proyectos y documentos con IA integrada.**

Aplicación de escritorio para Windows. Este repositorio contiene únicamente los
instaladores publicados, para que la app pueda actualizarse sola.

## Descargar

La última versión está en la sección **[Releases](../../releases/latest)**.

Descarga `S.HP_x.y.z_x64-setup.exe` y ejecútalo. Si ya tienes S.HP instalado,
no hace falta que descargues nada: la propia aplicación te avisará y se
actualizará sola.

## Qué hace

- Importa y organiza archivos reales de tu equipo (766 extensiones, 181 lenguajes)
- Busca dentro del contenido de PDF, Word, Excel, PowerPoint, ebooks y código
- Copiloto de IA local con Ollama: resúmenes, traducción, OCR y chat con tus documentos
- Bóveda cifrada con AES-256-GCM y Argon2id
- Papelera, deshacer, duplicados, etiquetas y proyectos personalizables

Todo funciona sin conexión. Tus archivos no salen de tu equipo.
